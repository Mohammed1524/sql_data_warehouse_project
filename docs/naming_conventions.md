# قواعد التسمية (Naming Conventions)

- **أسلوب التسمية:** `lowercase_snake_case` لكل الجداول والأعمدة والملفات.

- **السكيمات:** `raw` للداتا الخام، `metadata` لتسجيل المصادر، و `quality` لفحص الجودة.

- **المفاتيح التعريفية:** اسم الكيان متبوعاً بـ `_id` مثل `building_id` و `site_id`.

- **ملفات الكود:** تبدأ برقم الترتيب مثل `01_init_database.sql` و `01_data_quality_checks.sql`.

- **أسماء الجداول:** تعبر عن محتواها مباشرة بدون تواريخ أو أسماء شخصية.
